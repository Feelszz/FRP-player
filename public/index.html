ATIVAÇÃO DO APLICATIVO

Continue após o teste gratuito

O FPR Player oferece um teste gratuito de 7 dias. Para continuar usando o aplicativo com acesso permanente, o valor é de R$ 41,00, mediante pagamento via PIX.

Como receber e usar o código:
  1. Abra o FPR Player e entre em Configurações.
  2. Copie o ID do dispositivo exibido nessa tela.
  3. Preencha seu nome, sobrenome, e-mail e ID abaixo.
  4. Escaneie o QR Code Pix ao lado; o valor de R$ 41,00 já estará preenchido no banco.
  5. Após a confirmação, o código será enviado para o e-mail informado.
  6. No app, volte a Configurações, digite o código na área de ativação e toque em Ativar.
