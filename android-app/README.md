# FPR Player para Android

Aplicativo Android com a identidade visual do site. A playlist é importada dentro do aplicativo por link M3U ou arquivo local; o site público continua apenas como página de download.

## Build gratuito

O workflow `.github/workflows/android-apk.yml` compila `app-debug.apk` no GitHub Actions e publica o APK como artefato do workflow.

No GitHub: **Actions → Build FPR Player APK → Run workflow**. Depois, abra a execução concluída e baixe o artefato `fpr-player-apk`.
